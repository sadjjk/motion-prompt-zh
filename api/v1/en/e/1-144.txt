// Shake on error / エラー時のシェイク
// Pack: ui (UI component names) · element 46 · Category: Choosing & switching
// What happens: Six dots are typed into the password field and "Log in" is pressed; the field shakes, its border turns red and a red error message drops in below.
// Motion spec:
//   - A 300×44 password field; from 0.3 s one dot is typed every 0.12 s (6 in all), and "Log in" is pressed at 1.2 s.
//   - Over 1.35–1.8 s the field shakes sideways by 10·sin(8πp)·sin(πp), small to large to small; the border turns red in 0.15 s.
//   - The error message fades in over 1.45–1.75 s while sliding down 4px from above.
//   - Over 3.6–3.9 s the dots, red border and message fade out together to reset.
// When to use it: Use it in login, verification-code or required-field forms that should flag a mistake at once.
// Tags: shake, error, validation, password, login, form
// Size: 542x191 px · Cycle: 4.5 s
// Needs: kit ui -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/ui.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#1-144
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 46
// 改写自 KittenJam Motion Library #151 错误震动提示：300×44 密码框，0.3 秒起每 0.12 秒输入一个圆点（共 6 个），1.2 秒按下「登录」。
// 1.35–1.8 秒密码框左右震动：位移 10·sin(8πp)·sin(πp)，幅度由小到大再变小；边框 0.15 秒变红；
// 错误提示「密码错误，请再试一次」1.45–1.75 秒从上方 4px 滑下淡入；复位：3.6–3.9 秒圆点、红框与提示一起淡出。
CELLS[45] = ui((w, h, t) => {
  const fx = 121, fy = 34, fw = 300, fh = 44;
  const ndots = t < .3 ? 0 : Math.min(6, Math.floor((t - .3) / .12) + 1);
  const clear = 1 - seg(t, 3.6, 3.9);
  const p = seg(t, 1.35, 1.8);
  const dx = p > 0 && p < 1 ? 10 * Math.sin(p * Math.PI * 8) * Math.sin(p * Math.PI) : 0;
  const er = eo(seg(t, 1.35, 1.5)) * (1 - eo(seg(t, 3.6, 3.9)));
  text('密码', fx, 20, 12, C.hint, 600);
  X.save(); X.translate(dx, 0);
  fillRR(fx, fy, fw, fh, 8, '#fff'); strokeRR(fx, fy, fw, fh, 8, C.line2, 1.5);
  if (er > 0) strokeRR(fx, fy, fw, fh, 8, `rgba(229,72,77,${er})`, 2);
  X.save(); X.globalAlpha = clear;
  for (let i = 0; i < ndots; i++) circle(fx + 20 + i * 16, fy + fh / 2, 4.5, C.ink);
  X.restore();
  X.restore();
  const a = eo(seg(t, 1.45, 1.75)) * clear;
  if (a > 0) {
    const ey = 96 - 4 * (1 - a);
    X.save(); X.globalAlpha = a;
    circle(fx + 7, ey, 7, '#e5484d'); text('!', fx + 7, ey + .5, 10, '#fff', 800, 'center', NUMF);
    text('密码错误，请再试一次', fx + 20, ey, 12, '#e5484d', 600);
    X.restore();
  }
  const press = t >= 1.2 && t < 1.35;
  fillRR(fx, 118, fw, 38, 8, press ? '#1748c0' : C.blue);
  text('登录', fx + fw / 2, 137, 14, '#fff', 700, 'center');
});
