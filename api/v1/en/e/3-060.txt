// Leading lines / リーディングライン
// Pack: photo (Photo looks, lighting & styles) · element 28 · Category: Composition
// What happens: The two edges of a road converge from the bottom of the frame to a point in the distance; the person moves from off the road onto that point, and dashed lines flow along the edges towards him.
// Motion spec:
//   - Vanishing point at (380, 112); the road edges run from (150, 208) and (599, 208) to it.
//   - Subject: moves from x 120 off the road to the vanishing point at x 380, 40 px tall.
//   - Guide dashes are 8/6 px and flow towards the subject at 28 px per second, exactly 10 repeats per pass; labelled "引导线".
//   - Guides: amber #F5A524 dashed lines, 1.6 px wide, fading in with the effect amount.
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, ease-in-out).
// When to use it: To make the viewer find the subject at once, or to stress depth and direction.
// Tags: leading lines, converging lines, vanishing point, perspective, composition, depth
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/photo.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#3-060
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 28
// 引导线: 道路边线从画面下沿汇聚到远处；主体从路外移到汇聚点，虚线沿边线流向主体
CELLS[27] = cell((k, u) => {
  const a = env(u), VX = 380, VY = 112, D = field(k, BASE, VY);
  D.poly([[150, CH], [VX - 6, VY], [VX + 6, VY], [CW + 60, CH]], BASE.ground2);
  figure(D, lerp(120, VX, a), VY + 4, 40, BASE.person);
  // 虚线每秒流动 28 px；[8,6] 一周 14 px，5 秒正好 10 周，循环无缝
  k.save(); k.lineDashOffset = -u * 28;
  guide(k, [[150, CH], [VX - 6, VY + 2]], a, [8, 6]); guide(k, [[CW + 60, CH], [VX + 6, VY + 2]], a, [8, 6]);
  k.restore();
  tag(k, '引导线', 250, 176, a);
});
