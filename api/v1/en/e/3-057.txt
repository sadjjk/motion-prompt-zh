// Rule of thirds / 三分割法
// Pack: photo (Photo looks, lighting & styles) · element 25 · Category: Composition
// What happens: The person moves from the centre to the left third line and the horizon drops from the middle to the lower third, while two horizontal and two vertical third lines and their four crossings appear.
// Motion spec:
//   - Subject: x 270 → left third line at x 180; horizon: y 104 → lower third line at y 139.
//   - A tree moves from x 390 to the right third line at x 360, balancing the person.
//   - Third lines: verticals at x 180 and x 360, horizontals at y 69 and y 139; dots of radius 3.5 px mark the four crossings.
//   - Guides: amber #F5A524 dashed lines, 1.6 px wide, fading in with the effect amount.
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, ease-in-out).
// When to use it: For landscapes, portraits or street shots that should feel balanced but not stiff.
// Tags: rule of thirds, thirds, grid, composition, horizon, balance
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/photo.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#3-057
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 25
// 三分法: 主体从中央移到左三分线，地平线从中线降到下三分线；辅助线只是参照，不要求压线
CELLS[24] = cell((k, u) => {
  const a = env(u), hz = lerp(CH / 2, H3[1], a);
  const D = field(k, BASE, hz);
  tree(D, lerp(CW / 2 + 120, T3[1], a), hz, 16, BASE);
  figure(D, lerp(CW / 2, T3[0], a), hz + 30, 92, BASE.person);   // 头顶约在上三分线附近
  T3.forEach(X => guide(k, [[X, 0], [X, CH]], a)); H3.forEach(Y => guide(k, [[0, Y], [CW, Y]], a));
  k.save(); k.globalAlpha = a; k.fillStyle = GUIDE;   // 四个交点
  T3.forEach(X => H3.forEach(Y => { k.beginPath(); k.arc(X, Y, 3.5, 0, TAU); k.fill(); })); k.restore();
});
