// Close-up / クローズアップ
// Pack: camera (Camera moves & transitions) · element 30 · Category: Shot size
// What happens: Head and shoulders fill the frame: the eyes shift to one side, there is a blink, the body leans back a little, and finally the gaze returns to the front.
// Motion spec:
//   - Frame: 1.4 m to 1.85 m (shoulders to the top of the head); camera 2.6 m away.
//   - Gaze: shifts 0.05 m to one side from 0.4 s to 0.9 s and returns from 3.7 s to 4.4 s.
//   - A blink at 1.55 s; the body leans back 0.05 m from 0.9 s to 1.3 s and returns with the gaze.
//   - The background is clearly blurred; top right reads "特写 CU" and the scale band runs from the shoulders to the head.
//   - The camera never moves; one pass = 4.7 s and the first and last frames match.
// When to use it: For moments where the audience should catch a feeling, a reaction or a small change in expression.
// Tags: close-up, cu, close up, head and shoulders, reaction, shot size, emotion
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/camera.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#3-054
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 30
// 30 特写：胸像。动作只有特写才看得清：视线先动（被什么吸引）、一次眨眼、身体轻轻退半步，末段复原；首尾正视，循环无缝
CELLS[29] = shot(frameCell({ lo: 1.4, hi: 1.85, name: '特写', abbr: 'CU', draw: (k, w, h, u) => {
  const gaze = 0.05 * eOut(P(u, 0.4, 0.9)) * (1 - P(u, 3.7, 4.4));   // 视线先动：被什么吸引
  const sway = -0.05 * eOut(P(u, 0.9, 1.3)) * (1 - P(u, 3.7, 4.4));  // 身体轻轻退半步
  const blink = clamp(1 - Math.abs(u - 1.55) / 0.09);                // 注意到时眨一次眼
  world(k, w, h, fit(1.4, 1.85, 2.6), {
    person: { x: sway, z: 8, fg: true },
    extra: [[sway, 0, 7.99, (kk, s) => face(kk, s, { gaze, blink }), true]],
    blurBg: 2.0
  });
} }));
