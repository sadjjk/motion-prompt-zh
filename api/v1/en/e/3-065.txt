// Shot/reverse shot / 切り返し
// Pack: camera (Camera moves & transitions) · element 34 · Category: Transitions
// What happens: Over B's shoulder we see A speak, then a cut over A's shoulder to B answering, then back to A; the listener shows only shoulders and back. A stays on the left of the frame and B on the right throughout.
// Motion spec:
//   - Shot: camera 2.6 m to the right behind B, 1.5 m high, turned 0.741 rad to look at A over B's shoulder; the reverse is its mirror image.
//   - Cuts: to the reverse at 1.4 s and back at 2.8 s; the camera does not travel between them.
//   - Speech: A from 0.2 s to 1.3 s and 3.0 s to 4.0 s, B from 1.6 s to 2.7 s; the person with their back to the camera has no face drawn.
//   - Both cameras are on the same side of the line, so A stays left and B right; top right reads "正打 A" / "反打 B".
//   - Return: cross-fade back to the first shot over the last 0.5 s (one pass = 4.7 s).
// When to use it: The standard way to film a two-person conversation, showing both the speaker and the listener's reaction.
// Tags: shot reverse shot, shot/reverse shot, ots, over the shoulder, dialogue, cut, editing
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/camera.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#3-065
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 34
// 34 正反打：两个过肩机位直接交替，不在两点之间移动；说话的人在镜头里，听的人只露肩背。A 始终在画面左、B 始终在右
const OTS_A = cam({ x: 2.6, y: 1.5, z: 5.6, yaw: -0.741 }), OTS_B = cam({ x: -2.6, y: 1.5, z: 5.6, yaw: 0.741 });
CELLS[33] = shot(cutCell([
  [0, (k, w, h, u) => world(k, w, h, OTS_A, two({ buildings: false, blurBg: 1.2, faces: 'A', talkA: mouth(u, 0.2, 1.3) })), '正打 A'],
  [1.4, (k, w, h, u) => world(k, w, h, OTS_B, two({ buildings: false, blurBg: 1.2, faces: 'B', talkB: mouth(u, 1.6, 2.7) })), '反打 B'],
  [2.8, (k, w, h, u) => world(k, w, h, OTS_A, two({ buildings: false, blurBg: 1.2, faces: 'A', talkA: mouth(u, 3.0, 4.0) })), '正打 A']
]));
