// Extreme close-up / 大クローズアップ
// Pack: camera (Camera moves & transitions) · element 31 · Category: Shot size
// What happens: The frame holds only a band across the eyes: the gaze sweeps left and right once, with one quick blink along the way.
// Motion spec:
//   - Frame: 1.58 m to 1.72 m, a band across the eyes only 0.14 m tall; camera 2.0 m away.
//   - Gaze: sweeps left and right once per pass on a sine, 0.05 m each way, centred at the start and end.
//   - Blink: the eyes close from 2.4 s to 2.5 s and reopen from 2.6 s to 2.75 s.
//   - The background is heavily blurred; top right reads "大特写 ECU" and the scale shows only a thin band at the eyes.
//   - The camera never moves; one pass = 4.7 s and the first and last frames match.
// When to use it: To build tension, stress a key detail or show a character's inner moment.
// Tags: extreme close-up, ecu, xcu, eyes, detail, shot size, tension
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/camera.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#3-055
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 31
// 31 大特写：只框住眼带。视线左右扫一眼 + 一次干净利落的眨眼（wave 首尾回 0，循环无缝）
CELLS[30] = shot(frameCell({ lo: 1.58, hi: 1.72, name: '大特写', abbr: 'ECU', draw: (k, w, h, u) => {
  const gaze = 0.05 * wave(u, 1);                         // 一次左右扫视
  const blink = P(u, 2.4, 2.5) * (1 - P(u, 2.6, 2.75));   // 干净利落的眨眼
  world(k, w, h, fit(1.58, 1.72, 2.0), {
    person: { z: 8, fg: true },
    extra: [[0, 0, 7.99, (kk, s) => face(kk, s, { gaze, blink }), true]],
    blurBg: 2.4
  });
} }));
