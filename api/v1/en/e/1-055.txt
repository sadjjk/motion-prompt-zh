// Thinking orb: listening / 思考オーブ・聞き取り中
// Pack: aiux (AI interface motion) · element 07 · Category: Loading & thinking
// What happens: Rings of dots swell and shrink one after another from top to bottom, like a wave rolling over the orb.
// Motion spec:
//   - Orb radius 58 px with 11 latitude rings (−75° to 75°, every 15°), 8–34 dots per ring depending on latitude.
//   - Each ring's radius swells by up to ±10% (about 6 px); 2 waves per cycle, offset 0.7 rad from ring to ring.
//   - Swollen rings are brighter. The orb spins once per cycle.
//   - Label "Listening…" at 15 px on the right.
// When to use it: Use it while the mic is open for voice input, voice mode or dictation.
// Tags: thinking-orb, listening, voice, microphone, dictation, wave
// Size: 539x208 px · Cycle: 4.8 s
// Needs: kit aiux -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/aiux.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#1-055
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 07
// 07 思考球·聆听（state="listening"）：纬线环上的点随声波起伏，波沿纬度方向滚动
CELLS[6] = (k, w, h, u) => {
  bg(k);
  const spin = TAU * u / CYC;
  for (let i = 0; i < 11; i++) {
    const lat = (-75 + 15 * i) * Math.PI / 180, cl = Math.cos(lat);
    const amp = 0.1 * Math.sin(2 * TAU * u / CYC - i * 0.7);   // 振幅 ≈ 6 px，2 个波 / 周期
    const n = Math.max(8, Math.round(34 * cl));
    for (let j = 0; j < n; j++) {
      const lon = j * TAU / n, rr2 = cl * (1 + amp);
      dot(k, rot([rr2 * Math.cos(lon), Math.sin(lat), rr2 * Math.sin(lon)], spin, ORB.tilt), 0.8, Math.max(0, amp) * 4);
    }
  }
  orbLabel(k, 'Listening…');
};
