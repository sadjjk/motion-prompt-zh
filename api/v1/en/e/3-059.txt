// Symmetrical composition / シンメトリー構図
// Pack: photo (Photo looks, lighting & styles) · element 27 · Category: Composition
// What happens: A line of stepping stones runs up the middle the whole time; pairs of trees grow on both sides from near to far, mirroring each other across the centre line.
// Motion spec:
//   - 4 stepping stones sit on the centre line at x 270, larger near and smaller far, from y 196 up to y 136.
//   - 4 pairs of trees at 70, 120, 170 and 220 px from the centre line; pair i starts growing when the effect reaches 0.2i and is full within 0.4.
//   - The centre line is a vertical dashed line at x 270 labelled "对称轴" at the top.
//   - Guides: amber #F5A524 dashed lines, 1.6 px wide, fading in with the effect amount.
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, ease-in-out).
// When to use it: For architecture, corridors or reflections that are symmetrical already, or when the picture should feel stable and solemn.
// Tags: symmetry, symmetrical composition, mirror, axis, composition, balance
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/photo.js
// Live demo: https://sadjjk.github.io/motion-prompt-zh/?lang=en#3-059
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 27
// 对称构图: 中间的踏脚石一直在；两侧的树随 a 由近到远逐对长出，围绕中轴呼应
CELLS[26] = cell((k, u) => {
  const a = env(u), D = field(k, BASE, 120);
  [[196, 18], [172, 13], [152, 9], [136, 6]].forEach(([y, r]) => D.rr(CW / 2 - r, y, r * 2, r * 0.6, r * 0.3, BASE.edge));
  for (let i = 0; i < 4; i++) {   // 第 i 对在 a 走到 0.2i 时开始长，0.4 内长满（近大远小）
    const g = P(a, i * 0.2, i * 0.2 + 0.4); if (g <= 0) continue;
    const off = 70 + i * 50, r = (20 - i * 3.5) * g, base = 196 - i * 20;
    tree(D, CW / 2 - off, base, r, BASE); tree(D, CW / 2 + off, base, r, BASE);
  }
  guide(k, [[CW / 2, 0], [CW / 2, CH]], a); tag(k, '对称轴', CW / 2, 22, a);
});
