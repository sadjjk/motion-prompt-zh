Please use "Rolling digits" (桁ごとに回る数字), one of the names in "Interaction & data motion".
Motion Prompt #1-091

What it is: A counter where only the changed digits roll vertically to update
What the sample shows: Each update of a large live-visitor number rolls only the changed digits with a slight overshoot, while the trend line beside it shifts one step left.
Spec:
- Only changed digits roll, each for 0.9 s with cubic-bezier(.3,1.25,.5,1) overshoot, staggered 45 ms from left to right.
- 46 px digits roll upward when the value rises and downward when it falls; the top and bottom 14% fade out.
- In the demo the value changes at 1.0, 2.4, 3.8 and 5.2 s: 12,486 → 12,531 → 12,529 → 12,407.
- A 24-point trend line shifts one step left in 0.6 s on each update; a red dot pulses every 1.6 s.
When to use it: Use it for frequently changing numbers such as dashboard KPIs, live visitors, sales or prices.
