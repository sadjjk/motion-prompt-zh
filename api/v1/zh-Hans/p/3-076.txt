请使用“斑驳树影（Dappled light）”，属于“摄影光线与风格”。
Motion Prompt #3-076

效果解释：阳光穿过树叶，在人物和地面落下一块块亮斑
动画表现：画面沉入偏绿的树荫，人物、建筑和地面散落形状不一的光斑；风吹时光斑一起流动，相邻的时而相连时而分开；地面排着横长的圆形光斑，上方两角挂着虚焦的树叶。
实现规格与关键运动参数：
- 场景 1：头肩人物，头部中心 x 270、y 78、半径 29 px；整体“正片叠底” #7F9682 作为树荫。
- 光斑形状：在 1/4 尺寸（135×52）的小画布上点 64 个叶缝和 12 个地面横椭圆，模糊 1.1 px 后以 16 倍对比度二值化，相近的点会连在一起。
- 放大到全尺寸，模糊 1.6 px，“正片叠底” #FFE0A0 后以 0.92 不透明度“滤色”叠加。
- 风：整体偏移 = 1.6·sin(T) + 0.6·sin(3T+1)（小画布像素），再加每点各自的小摆动；上方左右角放模糊 7 px 的树叶 #3B5442，不透明度 0.55。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前回到原样；每轮 5 秒，缓入缓出。
适用场景：公园、树林、夏日午后的画面，想要安静又有生气的光线时。
