请使用“15 秒产品广告脚本（15-second ad script）”，属于“镜头与剪辑 / 分镜与节奏”。
Motion Prompt #3-095

效果解释：0–3 秒钩子，3–10 秒两个卖点，10–13 秒使用场景，最后 2 秒产品加口号的 15 秒广告结构
动画表现：4 个格子的宽度按 3 : 7 : 3 : 2 秒分配，一眼看出卖点段最长、结尾最短。「钩子」：杯子从上方掉下弹起，红字「摔不坏？」；「卖点 × 2」：前半段黑底侧光，防滑纹亮起，后半段冒热气，数字涨到 12h 并写「保温」；「使用」：户外手拿着杯子；「产品 + 口号」：浅蓝干净底色，杯子居中，下方蓝色口号条。格下写 3s、7s、3s、2s，角标显示已播秒数，如「07 / 15s」。
实现规格与关键运动参数：
- 9.4 秒周期。15 秒按每秒 0.55 秒压缩，从 0.3 秒播到 8.55 秒
- 格子宽度 3 : 7 : 3 : 2；「卖点 × 2」前半段是防滑纹，后半段是热气和从 0 涨到 12h 的数字
- 结尾格：口号条在本格 15–40% 处淡入
- 8.8–9.4 秒淡回开头画面
适用场景：写社交平台广告、电商 15 秒短片脚本，想先定好时间分配时。
