Motion Prompt #3-083

效果解释：光偏暖橙还是偏冷蓝，用开尔文（K）表示
动画表现：右下有开尔文刻度条，指针按 5500K → 2000K → 10000K → 5500K 移动；数值低时画面偏橙，高时偏蓝。
实现规格与关键运动参数：
- 场景：太阳位于 (432, 54) 的风景，加头肩人物，头部中心 x 140、y 82、半径 28 px。
- K 值变化：0.4～1.4 秒 5500 → 2000K，2.0～3.0 秒 → 10000K，3.6～4.6 秒 → 5500K，各段缓入缓出。
- 颜色：2000K #FF8A2A、2700K #FFA552、3500K #FFC489、5500K 无色、7500K #A9C8FF、10000K #7FA8FF，之间插值，以“正片叠底”叠加，最大强度 0.67。
- 刻度条：右下 150×34 px 白色标签，内有 2000～10000K 色带和三角指针；右上显示取整到 100K 的数值。
适用场景：讲解白平衡和偏色，或想用颜色表达时段与情绪时。
