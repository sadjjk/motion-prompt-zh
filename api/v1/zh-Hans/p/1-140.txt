Motion Prompt #1-140

效果解释：随滚动从中央扩大的圆形遮罩揭开下一章
动画表现：随滚动推进，深色第二章从浅色第一章中央以圆形扩开直到铺满；第一章标题缩小淡出，第二章标题由大缩回原尺寸；滚回时圆形缩回。
实现规格与关键运动参数：
- 滚动进度在 0.5–4.4 秒由 0 到 1（inOut3），右侧滚动条同步。
- 圆形遮罩半径随进度成比例地从 0 扩大到画面半对角线。
- 第一章标题缩到 0.8 并淡出；第二章标题从 1.2 倍缩回 1 倍。
- 5.4–6.3 秒滚动回退，圆形缩回。
适用场景：适合叙事型页面与产品介绍，强调章节或场景的切换。
