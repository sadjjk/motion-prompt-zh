Motion Prompt #3-057

效果解释：把主体和地平线放在三等分线附近
动画表现：人物从画面正中移到左三分线，地平线从中线降到下三分线，同时显出两横两竖的三分线和四个交点。
实现规格与关键运动参数：
- 人物：x 270 移到左三分线 x 180；地平线：y 104 降到下三分线 y 139。
- 树从 x 390 移到右三分线 x 360，与人物左右呼应。
- 三分线：竖线 x 180、x 360，横线 y 69、y 139；四个交点画半径 3.5 px 的圆点。
- 辅助线为琥珀色 #F5A524 虚线，线宽 1.6 px，随效果强度渐显。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前回到原样；每轮 5 秒，缓入缓出。
适用场景：风景、人像、街拍等想让画面平衡又不呆板的时候。
