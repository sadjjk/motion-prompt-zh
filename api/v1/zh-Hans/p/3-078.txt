Motion Prompt #3-078

效果解释：夜里只有前下方的火堆照亮人，暖橙色、会跳动，火光之外迅速沉入黑暗
动画表现：深蓝色的夜，右下方火堆的橙光照亮人物朝火的一侧，亮度随火焰跳动；光迅速衰减，火星向上飘。
实现规格与关键运动参数：
- 场景 1：头肩人物，夜空 #16224A；火堆位于 (382, 188)。
- 跳动：fl = 0.95 + 0.06·sin(7T) + 0.04·sin(13T+1) + 0.03·sin(23T+2)；照到人物的光从火堆出发，半径 170·fl，由 #FF9A3D 过渡到暗部。
- 四周黑暗：半径 330·fl 外过渡到 0.72 不透明度的 #040610；火焰分 3 层，高 34/26/15 px（#E8501E、#FF9A2E、#FFE07A）。
- 16 颗火星 #FFB34D 上升 150 px 后消失，每轮 1～2 次；右上显示“1800K”。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前回到原样；每轮 5 秒，缓入缓出。
适用场景：露营、野外、围炉夜谈等，想要温暖亲密的氛围时。
