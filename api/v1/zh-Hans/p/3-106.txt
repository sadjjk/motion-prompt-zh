请使用“氛围灯（Ambient lighting）”，属于“光线与色彩 / 氛围与调性”。
Motion Prompt #3-106

效果解释：关掉主灯，只留灯带、台灯、屏幕这些局部光，暗处多，色光有方向
动画表现：起点是普通亮着的卧室：床角、海报、书桌、显示器和台灯。先关掉主灯，整个房间暗下来；再让天花板附近的紫蓝灯带亮起，向下晕开；接着台灯亮起，在桌面落下一锥暖光；最后显示器亮成冷蓝，往四周和桌面洒一点冷光，只剩一暖一冷的局部光。右侧清单每加入一项，对应的编号圆点变蓝，状态从「平淡版」变为「叠加中」再到「成品」。
实现规格与关键运动参数：
- 5 秒周期。0–0.6 秒是平淡版；4 项成分从 0.6 秒起每 0.7 秒加入下一项，各用 0.5 秒渐入
- 关主灯后整体压暗 0.72；灯带是天花板下一条 3 px 的线，向下晕开
- 台灯：桌面上一锥暖光，半径 80 px；屏幕：亮成冷蓝，向四周洒光，半径 120 px
- 成品停到 4.4 秒，4.4–4.95 秒退回平淡版，5 秒与 0 秒是同一帧
适用场景：拍房间、桌面、电竞房、咖啡店的夜景，想要暗一点、放松的气氛时。
