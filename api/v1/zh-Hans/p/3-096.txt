Motion Prompt #3-096

效果解释：很扁的横幅，主体放在正中、两侧可以被裁，转发时裁成正方形也完整
动画表现：上下两行是同一张海边横幅。正中出现琥珀色虚线正方形框，框外压白；裁出的正方形滑到右边：上行人物居中，正方形里人完整，绿框 ✓「主体居中」；下行人物偏左，正方形把人裁掉一半，红框 ✕「主体偏一侧」。上方标「横幅 2.35 : 1」「正方形 1 : 1」。
实现规格与关键运动参数：
- 5 秒周期。0.3–0.8 秒出现 2.35 : 1 横幅，1.0–1.6 秒出现中间的正方形框和框外压白（不透明度 0.62）
- 1.9–2.6 秒裁出的正方形滑到右侧 x 318，边框绿 = 完整、红 = 被裁坏
- 2.8–3.2 秒出现 ✓ / ✕ 结论
- 4.4–4.95 秒全部收回，5 秒与 0 秒是同一帧
适用场景：做公众号头图、横幅 Banner 等之后会被裁成别的比例的图时。
