请使用“价格方案切换（Pricing toggle）”，属于“UI 组件”。
Motion Prompt #1-114

效果解释：切换月付 / 年付时价格数字滚动变化
动画表现：光标点“年付”，滑块移过去，三张卡的价格依次滚动成新值，中间推荐卡放大并描蓝边，之后切回月付。
实现规格与关键运动参数：
- 160×30“月付 / 年付”胶囊开关，3 张价格卡（150×124、间距 18）。
- 光标 1.0 秒点“年付”，滑块 0.3 秒（easeInOut 3 次方）右移。
- 三张卡价格依次（间隔 0.08 秒、各 0.4 秒）向上滚动到新值：¥29 / 59 / 99 → ¥23 / 47 / 79。
- 中间推荐卡 0.35 秒放大到 1.06 并描 2px 蓝边，开关旁“省 20%”淡入。
- 3.2 秒点“月付”，全部以同样方式切回。
适用场景：适合 SaaS 价格页等按付费周期变价的方案对比。
