请使用“青绿山水（Blue-green landscape）”，属于“东方传统 / 书画”。
Motion Prompt #4-037

效果解释：用石青、石绿矿物颜料重彩画山的中国山水画风格
动画表现：绢本长卷缓缓横移，远、中、近 3 层山各以不同速度平移。每座山是主峰两侧叠着子峰的一簇，山顶圆、山壁陡。起初只有墨线和披麻皴，随后石青、石绿自上而下染开，山脚压赭石。山脊上有苔点和小松，中景山头有一座小亭，山脚云带飘过，近景山谷里有石桥和桥上的人，江上一叶小舟。最后颜色退回墨线。
实现规格与关键运动参数：
- 6.4 秒周期。远、中、近 3 层画卷周期为 540 / 810 / 1080 px，速度 0.5 / 0.75 / 1，每周期正好平移一个画卷周期，首尾相接
- 0.6–2.6 秒石青、石绿、赭石自上而下染开
- 水纹间距 45 px，小舟每周期起伏 2 次
- 5.4–6.0 秒颜色退回墨线
适用场景：适合国风、传统文化、文旅宣传，或作为舒缓的背景动画。
