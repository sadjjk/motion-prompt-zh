请使用“翻页书（Page flip）”，属于“UI 组件”。
Motion Prompt #1-119

效果解释：书页以书脊为轴翻到另一侧
动画表现：光标两次点开着的书的右页，每次一张纸以书脊为轴收窄、翻面落到左侧；最后点左页，两张纸一起翻回。
实现规格与关键运动参数：
- 摊开的书：2 页 150×148，在 x 271 的书脊处相接。
- 光标在 0.9 秒、2.1 秒点右页，每次一张纸以书脊为轴 0.7 秒翻过去：scaleX 按 cos(π·easeInOut) 从 1 到 −1。
- 过 0 后显示背面，接近 0 时叠加最多 0.25 的暗影模拟立体感；页码 1-2 → 3-4 → 5-6。
- 3.4 秒点左页：上层纸 3.5 秒、下层纸 3.6 秒起各 0.55 秒翻回，回到 1-2。
适用场景：适合目录、绘本、作品集、年报等想保留纸张翻阅感的阅读界面。
