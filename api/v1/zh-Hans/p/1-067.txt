请使用“阅读句子聚焦（Sentence reading focus）”，属于“交互与数据动效”。
Motion Prompt #1-067

效果解释：只让指针下那句话保持清晰的阅读聚焦模式
动画表现：指针移到哪句，哪句就变清晰，其余变淡变模糊，左侧紫色竖条跟着移动并伸缩到句高。
实现规格与关键运动参数：
- 段落 5 句话只留当前句清晰，其余降到 25% 透明度并轻微模糊，过渡 .45 秒。
- 左侧 4px 宽的紫色竖条移到当前句并伸缩到句高（.55 秒弹簧）。
- 顶部计数器「N / 5」按 16px 一格滚动（.5 秒弹簧）。
- 演示中指针在 0 / 1.2 / 2.2 / 3.2 / 4.2 秒依次移到第 1→5 句，5.6 秒回到第 1 句。
适用场景：适合博客长文、帮助文档、学习类 App 的阅读模式，帮读者不跟丢当前位置。
