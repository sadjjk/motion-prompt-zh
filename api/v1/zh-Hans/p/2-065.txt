Motion Prompt #2-065

效果解释：两列反向行进的波叠加，时而相长时而相消的图解
动画表现：青色波 A 与橙色波 B 反向流动，下方合成波时而加高时而压平，竖直采样虚线上 3 个点跟着读数。
实现规格与关键运动参数：
- 3 条泳道：波 A（青 #67e8f9）与波 B（橙 #ffb454）反向行进，合成泳道逐点相加 y₁ + y₂；a = sin(0.012x + φ)、b = sin(0.012x − 0.62φ + 1.08)，源波振幅 58、合成 66。
- 面板 0.07–0.42 秒由 0.96 倍放大并淡入；波 A、B 自 0.25 / 0.34 秒起用 0.36 秒从左 20px 滑入；合成泳道 0.59 秒起从下 20px 滑入。
- 合成波振幅 0.88–1.62 秒由 0 增到满；相位 0.6–3.74 秒匀速走 5π；“+”号 0.8 秒起用 0.23 秒回弹放大。
- 采样虚线 1.4 秒淡入，3 个采样点 1.44 秒起每隔 0.044 秒回弹出现；合成线宽 1.87–2.97 秒按正弦脉动 2 次（2.7→3.9px）；4.22–4.39 秒内容淡出，只留背景网格。
- 与波浪文字不同：是 2 列波叠加成合成波的物理图解，读数随相位实时变化，不是让文字起伏。
适用场景：适合物理或信号处理课程视频、教育类 App、声学与通信技术讲解，以及数据解说视频的插入镜头。
