Motion Prompt #3-069

效果解释：亮部柔和晕开、对比降低，轮廓仍在
动画表现：整张画面的模糊副本提亮后叠上，太阳和人物亮边晕开，暗部微微发灰，但山、树、人物的轮廓依然清楚。
实现规格与关键运动参数：
- 场景：太阳位于 (432, 54) 的风景，加头肩人物，头部中心 x 140、y 82、半径 28 px。
- 光晕：画面副本模糊 7 px、亮度 ×1.12，以 0.6 不透明度“滤色”叠加。
- 对比：再叠 0.1 不透明度的白色抬起暗部；原图留在下层，所以轮廓不糊。
- 右上显示“SOFT n%”。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前回到原样；每轮 5 秒，缓入缓出。
适用场景：人像、婚礼、回忆画面中，想营造柔和、朦胧的氛围时。
