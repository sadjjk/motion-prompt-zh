请使用“快捷键逐键点亮（Keyboard shortcut press）”，属于“UI 组件”。
Motion Prompt #1-111

效果解释：组合键一枚枚按下并点亮
动画表现：深色键盘板上 Ctrl、Shift、P 依次按下亮成琥珀色，提示文字逐步拼出，键盘板轻轻一跳后变为“已排队”。
实现规格与关键运动参数：
- 深色键盘板 510×168 上 3 枚键 Ctrl / Shift / P（宽 87 / 87 / 55、高 55、键距 8.7、圆角 8.7），1.10 / 1.45 / 1.85 秒依次按下并保持。
- 按下时键面由 #292524 变琥珀 #fbbf24、边 #f59e0b，键身下沉 2.5px，底部投影由 5px 黑 #0c0a09 缩成 2.5px 棕 #92400e（瞬时切换）。
- 提示：“按下即可发布”→ 1.45 秒“Ctrl + Shift + P”→ 1.85 秒整组琥珀并加上“· 发布”→ 2.6 秒“已排队”；2.2–2.6 秒键盘板放大到 1.02 倍再回到 1（每程 0.2 秒）。
- 3.2–3.95 秒键盘板以 sine.inOut 上浮 5px；复位 3.95–4.35 秒 easeInOutCubic，3 键同时抬起，提示交叉淡回“按下即可发布”。
- 与悬浮提示不同：用键帽按下的过程演示组合键，提示随按键进度逐步完整，不是附在按钮旁的说明。
适用场景：适合应用或开发工具的功能介绍、新手引导、快捷键清单和更新日志里的操作说明。
