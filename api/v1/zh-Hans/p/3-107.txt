请使用“质感（Tactile texture）”，属于“光线与色彩 / 氛围与调性”。
Motion Prompt #3-107

效果解释：让人一看就知道是什么材料、摸起来是什么感觉
动画表现：起点是桌上一只陶杯的平淡画面。先推到特写，杯子变大；再让低角度光从左边掠过，杯身左亮右暗，表面颗粒左上亮、右下有小影子，一颗颗凸出来，桌上拉出长影；接着左侧出现一道柔和模糊的竖向高光；最后出现 3 道细划痕，每道是一条暗线加一条亮边。右侧清单每加入一项，对应的编号圆点变蓝，状态从「平淡版」变为「叠加中」再到「成品」。
实现规格与关键运动参数：
- 5 秒周期。0–0.6 秒是平淡版；4 项成分从 0.6 秒起每 0.7 秒加入下一项，各用 0.5 秒渐入
- 推到 2.3 倍特写；低角度侧光从左边来：左亮右暗，90 颗颗粒各有左上亮点和右下阴影，桌上拉出长影
- 柔和高光：左侧一个模糊 2 px 的竖长椭圆；3 道划痕各是一条暗线配一条亮边
- 成品停到 4.4 秒，4.4–4.95 秒退回平淡版，5 秒与 0 秒是同一帧
适用场景：拍陶瓷、皮具、木器、布料等产品，想传达材料手感时。
