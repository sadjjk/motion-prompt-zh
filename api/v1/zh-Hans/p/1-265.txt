请使用“丝绸褶皱（Silk folds）”，属于“页面 / 首屏背景”。
Motion Prompt #1-265

效果解释：一块暗金色绸缎铺满画面，褶皱像被风吹着缓慢起伏，褶皱脊上滑过柔亮光泽的背景
动画表现：暗金色的布铺满画面，褶皱一边变形一边起伏；褶皱脊上流过柔光，凹处沉入阴影，整面带细颗粒。
实现规格与关键运动参数：
- 没有模拟：褶皱高度 = 0.62 · sin(6 (0.82 q + 0.57 y) + a + 1.5 sin(3q − 1.7y − a)) + 0.38 · sin(3.2 (0.5 q − 0.87 y) + 2a + 0.9 sin(2.4y + a))，其中 q = x + 0.2 sin(2.1y + 0.5x + a)，a = 2π·u / 6.4。
- 在 270×104 网格（每格约 2 px）上计算后放大。
- 法线：高度梯度 × 0.22；漫反射光源方向 (−0.45, −0.55, 0.7)，取 1.3 次方，凹处按高度最多压暗 40%。
- 光泽：半程向量高光，指数 28，按 0.55 叠加 #FFE5BD。
- 颜色按光照在 #0D0906 与 #7C5631 之间插值，再按像素乘 1 ± 7% 的亮度颗粒。
适用场景：高端品牌、美妆、珠宝的首屏，或邀请函、活动页的背景。
