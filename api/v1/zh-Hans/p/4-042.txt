Motion Prompt #4-042

效果解释：近黑底只放正在讲的公式和图形、按概念配色、靠一个对象平滑运动讲清楚的数学讲解画风
动画表现：黑底上坐标轴从原点长出、刻度依次亮起，右上角逐字浮现 y = sin x；蓝色曲线从左描到右，金点和切线随之滑动，波峰波谷斜率为 0 时变红；最后全部渐暗。
实现规格与关键运动参数：
- 底色 #0F1014；0.2–0.9 秒坐标轴从原点长出，刻度 π/2、π、3π/2、2π 与 ±1 每隔 0.12 秒淡入。
- 从 0.6 秒起右上角蓝色 #58C4DD 公式 y = sin x 逐字从下方浮现，每字 0.08 秒。
- 1.6–4.6 秒从左描出正弦曲线（2π 占 420 px，振幅 62 px），金点 #F4D35E 和 84 px 长的切线跟着走。
- 读数 k = cos x 实时更新；斜率接近 0 的波峰波谷处切线和读数变红 #FC6255。5.4–6.0 秒全部渐暗归零。
适用场景：适合数学、统计、AI 概念讲解，以及需要让函数和图像动起来的场合。
