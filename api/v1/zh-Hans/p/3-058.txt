Motion Prompt #3-058

效果解释：把主体放在画面正中，视线直接落在它身上
动画表现：人物从左侧移到画面中轴，显出中轴线和头胸位置的视觉重心圈；背景左边是建筑、右边是树，并不对称。
实现规格与关键运动参数：
- 人物：x 150 移到中轴 x 270，身高 110 px。
- 中轴线为 x 270 的竖向虚线；视觉重心圈半径 28 px，圆心 y 118，右侧标“视觉重心”。
- 背景不镜像：左侧 x 60 有建筑，右侧 x 432、x 470 有两棵树，说明居中看的是重心。
- 辅助线为琥珀色 #F5A524 虚线，线宽 1.6 px，随效果强度渐显。
- 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前回到原样；每轮 5 秒，缓入缓出。
适用场景：产品图、证件感人像、强调唯一主角或制造正式感时。
