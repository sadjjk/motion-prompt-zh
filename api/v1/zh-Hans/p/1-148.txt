Motion Prompt #1-148

效果解释：浮动“+”按钮展开一列小操作按钮
动画表现：光标点右下蓝色 +，按钮旋转 135° 变成 ×，页面变暗；上方 3 个带标签的小按钮自下而上弹出，再点一次按相反顺序收回。
实现规格与关键运动参数：
- 右下半径 22 的蓝色 + 按钮；光标 0.9 秒点击，按钮 0.3 秒（easeOut 3 次方）旋转 135° 成 ×，页面盖上 0.35 的暗层。
- 上方 3 个半径 16 的小按钮（间距 44）自下而上每隔 0.06 秒弹出，各 0.3 秒以 back.out(1.4) 从 0.3 倍、低 12px 处放大，左侧带文字标签。
- 1.9–2.6 秒光标停在“拍照”上，底色变浅蓝。
- 3.2 秒再点一次，小按钮自上而下每隔 0.05 秒、各 0.2 秒收回，按钮转回 +。
适用场景：适合把笔记、拍照、分享等常用新建操作收进一个按钮的移动应用。
