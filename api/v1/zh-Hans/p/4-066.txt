Motion Prompt #4-066

效果解释：暗色画面上一句一屏的超大字幕，关键词压黄色色块、数字滚动落定，静音也能看懂的短视频新闻画风
动画表现：暗色画面上夜间街景的光斑横向漂移。左侧黄竖条伸出，「外卖平均」逐字打出。接着大号数字从 0 滚到 28 落定，右侧计时环的黄弧跟着长。黄色色块从左铺过「28 分钟」，块内的字反成黑色。补充句逐字出现，最后来源小字从下方滑入。复位时字幕整体上移出画面。
实现规格与关键运动参数：
- 数字：1.0–2.0 秒从 0 滚到 28
- 黄块：2.05–2.4 秒铺过「28 分钟」，块内字反黑
- 计时环：弧长 = 数字 / 60 分钟
- 来源小字：3.6 秒从下方滑入
- 复位：5.4–6.0 秒字幕整体上移 208 px
适用场景：适合数据新闻、有反转的故事、静音也要看懂的快讯。
