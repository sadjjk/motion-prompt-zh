请使用“拒收超大文件的上传框（Upload drop box that refuses big files）”，属于“组件 / 弹出与覆盖”。
Motion Prompt #1-252

效果解释：拖进来的文件会被框吞进去显示上传；超过上限的文件让框像摇头一样抖一下、变红并把文件弹回去，同一个文件再试一次，提示会换成一句带点调侃的话
动画表现：明黄到金黄的渐变底上，右边是一块投下琥珀色阴影的蓝色圆角投放框，里面是白色箭头小方块和 Drag a file here、Up to 5 MB 两行字。左边托盘放着绿色 PNG 标签的 mood.png 和紫色 MP4 标签的 demo.mp4。指针拿起图片拖到框上，框鼓起来变成更亮的蓝，箭头上抬，文字换成 Drop to upload。松手后图片压扁成细条被吸进中心，框收成一条上传行，百分比数字滚上去，薄荷绿进度条填满，绿色的勾弹出来。图片回到托盘后，视频被拖进框里：框左右抖一下、变红，说 Too big — up to 5 MB，视频被弹回托盘。再拖一次，提示换成 Still 12.6 MB. It didn't shrink.，过一会儿文字消失，框变回蓝色。
实现规格与关键运动参数：
- 投放框 300×176 px，圆角 20 px，黄底上的蓝色；显示 Drag a file here 和 Up to 5 MB，左边托盘放着 mood.png（2.4 MB）和 demo.mp4（12.6 MB）。
- 0.5 秒指针拿起图片（放大到 1.08 倍，最多倾斜 6°）移到框上，框放大到 1.02 倍、箭头上抬 4 px，文字换成 Drop to upload；1.0 秒松手，文件用 0.38 秒被吸进中心。
- 框收成上传行的大小；1.22 秒到 2.57 秒百分比滚动、薄荷绿进度条填满（1.35 秒，原作 speed 50 时为 2.37 秒，为装进一个周期而缩短），随后弹出绿色的勾，3.27 秒图片弹回托盘。
- 2.95 秒把 12.6 MB 的视频拖进框，3.55 秒松手：框左右抖 0.42 秒、变红，显示 Too big — up to 5 MB，文件按 bounce 40 的弹簧用 0.42 秒回到原位。
- 4.38 秒同一个文件再拖进来，提示换成 Still 12.6 MB. It didn't shrink.；提示在第一次拒收 1.8 秒后的 5.35 秒消失，框变回蓝色。
适用场景：适合文件上传页、附件选择和有大小限制的投稿表单，需要明确拒收超大文件又不想显得生硬时使用。
