Motion Prompt #1-145

效果解释：点击时方框弹一下，勾像笔画出
动画表现：光标依次点 3 个勾选框，方框缩一下再弹起、填蓝并画出白勾，文字加删除线变灰；最后点“清除”复原。
实现规格与关键运动参数：
- 3 条待办（行距 42），方框 22×22；光标在 0.8、1.5、2.2 秒依次点方框。
- 0.4 秒内方框先缩到 0.85、再弹到 1.1 后回 1；底色 0.15 秒填蓝，白勾在 0.1–0.35 秒从左下画到右上。
- 文字在 0.2–0.5 秒从左到右加删除线（easeInOut 3 次方）并变灰。
- 3.35 秒点“清除”，3 项 0.3 秒内同时复原。
适用场景：适合待办、购物清单、检查表等想强化完成手感的列表。
