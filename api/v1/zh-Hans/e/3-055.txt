// 运动规格:
//   - 画框：1.58 m 至 1.72 m，只有 0.14 m 高的眼部；机位距人物 2.0 m。
//   - 视线：每轮按正弦左右扫一次，幅度 0.05 m，首尾都在正中。
//   - 眨眼：2.4 秒至 2.5 秒闭眼，2.6 秒至 2.75 秒睁开。
//   - 背景强烈虚化；右上角显示“大特写 ECU”，比例尺只有眼部一条细带。
//   - 机位全程不动；每轮 4.7 秒，首尾画面相同。
// 适用场景: 制造紧张感、强调关键细节，或表现角色内心的瞬间。

// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 31
// 31 大特写：只框住眼带。视线左右扫一眼 + 一次干净利落的眨眼（wave 首尾回 0，循环无缝）
CELLS[30] = shot(frameCell({ lo: 1.58, hi: 1.72, name: '大特写', abbr: 'ECU', draw: (k, w, h, u) => {
  const gaze = 0.05 * wave(u, 1);                         // 一次左右扫视
  const blink = P(u, 2.4, 2.5) * (1 - P(u, 2.6, 2.75));   // 干净利落的眨眼
  world(k, w, h, fit(1.58, 1.72, 2.0), {
    person: { z: 8, fg: true },
    extra: [[0, 0, 7.99, (kk, s) => face(kk, s, { gaze, blink }), true]],
    blurBg: 2.4
  });
} }));
