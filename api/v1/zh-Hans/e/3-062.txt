// 框中框 / Frame within a frame
// 分类包: photo (摄影光线与风格) · element 30 · 子分类: 构图
// 动画表现: 近处的深色门框淡入，把远处站着的人物再框一次；门框内沿有一条浅色边，看得出它有厚度。
// 运动规格:
//   - 人物站在画面中央 x 270，身高 56 px；背景左侧有树、右侧有建筑。
//   - 门洞：宽 168 px，从 y 30 到画面底边，左右居中；门洞外填深色 #33405A。
//   - 门框内沿留 6 px 浅色边 #CFCECB，表示门框有厚度；虚线勾出门洞，顶部标“框中框”。
//   - 辅助线为琥珀色 #F5A524 虚线，线宽 1.6 px，随效果强度渐显。
//   - 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前回到原样；每轮 5 秒，缓入缓出。
// 适用场景: 想把视线收拢到主体、增加层次，或表现窥视、隔阂感时。
// 标签: frame within a frame, framing, doorway, window, composition, depth
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 动画演示: https://sadjjk.github.io/motion-prompt-zh/?lang=zh-Hans#3-062
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 30
// 框中框: 近处的门框淡入，把远处的主体再框一次；门框内沿留一条浅色边，表示它有厚度（不是后期加的装饰边框）
CELLS[29] = cell((k, u) => {
  const a = env(u), D = field(k, BASE, 150);
  tree(D, 120, 150, 14, BASE); building(D, 400, 150, 44, 50, BASE, 4);
  figure(D, CW / 2, 162, 56, BASE.person);
  const hx = CW / 2 - 84, hy = 30, hw = 168, hh = CH - 30;
  k.save(); k.globalAlpha = a;
  k.fillStyle = BASE.shade; k.beginPath(); k.rect(0, 0, CW, CH); k.rect(hx, hy, hw, hh); k.fill('evenodd');
  k.fillStyle = BASE.edge; k.fillRect(hx - 6, hy - 6, hw + 12, 6); k.fillRect(hx - 6, hy, 6, hh); k.fillRect(hx + hw, hy, 6, hh);
  k.restore();
  guide(k, [[hx, hy], [hx + hw, hy], [hx + hw, CH], [hx, CH], [hx, hy]], a);
  tag(k, '框中框', CW / 2, 16, a);
});
