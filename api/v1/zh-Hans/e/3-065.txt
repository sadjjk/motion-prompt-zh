// 正反打 / Shot/reverse shot
// 分类包: camera (镜头运动与剪辑) · element 34 · 子分类: 剪辑与转场
// 动画表现: 越过 B 的肩拍 A 说话，切到越过 A 的肩拍 B 回话，再切回 A；听的人只露肩背。A 一直在画面左边，B 一直在右边。
// 运动规格:
//   - 正打：机位在 B 身后右侧 2.6 m、高 1.5 m，转向 0.741 rad 越肩看 A；反打与之左右对称。
//   - 切点：1.4 秒切到反打，2.8 秒切回正打；机位之间不移动。
//   - 说话：A 在 0.2 秒至 1.3 秒、3.0 秒至 4.0 秒，B 在 1.6 秒至 2.7 秒；背对镜头的人不画脸。
//   - 两个机位都在轴线同侧，A 始终在左、B 始终在右；右上角显示“正打 A”/“反打 B”。
//   - 最后 0.5 秒交叉淡化回第一个镜头，每轮 4.7 秒。
// 适用场景: 拍两人对话的标准做法，让观众看到说话的人和听的人的反应。
// 标签: shot reverse shot, shot/reverse shot, ots, over the shoulder, dialogue, cut, editing
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://sadjjk.github.io/motion-prompt-zh/?lang=zh-Hans#3-065
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 34
// 34 正反打：两个过肩机位直接交替，不在两点之间移动；说话的人在镜头里，听的人只露肩背。A 始终在画面左、B 始终在右
const OTS_A = cam({ x: 2.6, y: 1.5, z: 5.6, yaw: -0.741 }), OTS_B = cam({ x: -2.6, y: 1.5, z: 5.6, yaw: 0.741 });
CELLS[33] = shot(cutCell([
  [0, (k, w, h, u) => world(k, w, h, OTS_A, two({ buildings: false, blurBg: 1.2, faces: 'A', talkA: mouth(u, 0.2, 1.3) })), '正打 A'],
  [1.4, (k, w, h, u) => world(k, w, h, OTS_B, two({ buildings: false, blurBg: 1.2, faces: 'B', talkB: mouth(u, 1.6, 2.7) })), '反打 B'],
  [2.8, (k, w, h, u) => world(k, w, h, OTS_A, two({ buildings: false, blurBg: 1.2, faces: 'A', talkA: mouth(u, 3.0, 4.0) })), '正打 A']
]));
