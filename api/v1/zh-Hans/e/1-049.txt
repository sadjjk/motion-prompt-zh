// 动画表现: 一道头亮尾淡的彩虹色光束，沿深色输入框的边框顺时针不停绕行。
// 运动规格:
//   - 输入框 380 × 64 px，圆角 16 px；光束顺时针匀速绕行，4.8 秒一圈。
//   - 光束长度为边框周长的 22%，向尾部按 1.5 次方渐隐，头部有白色亮点。

//   - 色相从尾到头变化 150°，整体配色每周期旋转 360°。
// 适用场景: 适合 AI 回复、智能体任务等超过约 3 秒的等待，加在正在工作的输入框或卡片上。

// @element 01
// 01 环绕光束（border-beam size="md"）：一道彩色光沿输入框边框顺时针绕行，一圈 4.8 秒
CELLS[0] = (k, w, h, u) => {
  bg(k);
  const x = 79.5, y = 72, W = 380, H = 64, R = 16;
  field(k, x, y, W, H, R, 'Ask anything…');
  beam(k, x, y, W, H, R, u / CYC, 0.22, 200 + 360 * u / CYC);
};
