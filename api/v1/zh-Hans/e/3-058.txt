// 居中构图 / Centered composition
// 分类包: photo (摄影光线与风格) · element 26 · 子分类: 构图
// 动画表现: 人物从左侧移到画面中轴，显出中轴线和头胸位置的视觉重心圈；背景左边是建筑、右边是树，并不对称。
// 运动规格:
//   - 人物：x 150 移到中轴 x 270，身高 110 px。
//   - 中轴线为 x 270 的竖向虚线；视觉重心圈半径 28 px，圆心 y 118，右侧标“视觉重心”。
//   - 背景不镜像：左侧 x 60 有建筑，右侧 x 432、x 470 有两棵树，说明居中看的是重心。
//   - 辅助线为琥珀色 #F5A524 虚线，线宽 1.6 px，随效果强度渐显。
//   - 效果在 0.4 秒至 1.4 秒进入，保持到 4.0 秒，在 4.8 秒前回到原样；每轮 5 秒，缓入缓出。
// 适用场景: 产品图、证件感人像、强调唯一主角或制造正式感时。
// 标签: centered composition, central composition, center framing, bullseye, composition, visual weight
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/photo.js
// 动画演示: https://sadjjk.github.io/motion-prompt-zh/?lang=zh-Hans#3-058
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 26
// 居中构图: 主体移到中轴，标出中轴与视觉重心；背景故意不镜像（左建筑、右树），说明居中看的是重心，不是对称
CELLS[25] = cell((k, u) => {
  const a = env(u), D = field(k, BASE, 150);
  building(D, 60, 150, 40, 46, BASE, 1); tree(D, 470, 150, 18, BASE); tree(D, 432, 150, 11, BASE);
  figure(D, lerp(150, CW / 2, a), 178, 110, BASE.person);
  guide(k, [[CW / 2, 0], [CW / 2, CH]], a);
  k.save(); k.globalAlpha = a; k.strokeStyle = GUIDE; k.lineWidth = 2; k.beginPath(); k.arc(CW / 2, 118, 28, 0, TAU); k.stroke(); k.restore();
  tag(k, '视觉重心', CW / 2 + 76, 118, a);
});
