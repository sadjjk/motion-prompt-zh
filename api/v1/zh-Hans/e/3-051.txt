// 中全景 / Medium long shot
// 分类包: camera (镜头运动与剪辑) · element 27 · 子分类: 景别
// 动画表现: 画框下沿落在膝盖，人物抬腿跨出一步再收回，大腿抬起落下的弧线看得清楚，背景轻微虚化。
// 运动规格:
//   - 画框：0.42 m 至 1.92 m，即膝盖以上到头顶；机位距人物 4.2 m。
//   - 动作：0.4 秒至 1.0 秒跨出 0.28 m，腿的抬起和落下都在画内；3.4 秒至 4.0 秒收回。
//   - 人物在前景层保持清晰，背景轻微虚化。
//   - 右上角显示“中全景 MLS”；右下角比例尺的蓝色带从膝盖到头顶。
//   - 机位全程不动；每轮 4.7 秒，首尾画面相同。
// 适用场景: 人物有走动或肢体动作，又想让观众看到表情时，常用于两三人的对话场面。
// 标签: medium long shot, mls, medium full shot, cowboy shot, knee shot, shot size, framing
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 动画演示: https://sadjjk.github.io/motion-prompt-zh/?lang=zh-Hans#3-051
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用方已清空并包裹 save/restore；w、h 为尺寸，u 为 [0, cycle) 内的秒数。画面仅由 u 决定。
// 以下为元素代码，CELLS、常量和辅助函数位于共享 kit 中。

// @element 27
CELLS[26] = shot(frameCell({ lo: 0.42, hi: 1.92, name: '中全景', abbr: 'MLS', draw: (k, w, h, u) => {
  const step = eIO(P(u, 0.4, 1.0)) * (1 - P(u, 3.4, 4.0));   // 跨步弧线：抬腿 → 落脚 → 收回
  world(k, w, h, fit(0.42, 1.92, 4.2), {
    person: { x: step * 0.28, walk: step * Math.PI * 0.8, z: 8, fg: true }, blurBg: 1.4
  });
} }));
