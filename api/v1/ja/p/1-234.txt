「コンテキスト使用量バー（Context meter）」を使ってください。分類は「フィードバック / AI の状態表示」です。
Motion Prompt #1-234

どういうものか: モデルのコンテキストを種類ごとの色分けバーで見せ、指した種類だけを残して数字をその量に回し、圧縮で会話の分を縮める
見本で起きること: 淡いミントのグラデーションの地に深い松葉色のカードがあり、白い「Context」の見出しとミント色の「Compact」ボタン、大きな「175.6K of 200K」、色分けされた横長のバー、種類ごとのチップが並ぶ。ポインタが入ってバーの細い琥珀色の区画を指すと、ほかの区画が薄くなり、数字が桁ごとに転がって「4.2K System」になる。次に青い Files、続いて大きな青緑の Chat を指すと、そのたびに数字がその量へ回る。ポインタがバーを離れると合計に戻り、右上の「Compact」を押すと Chat の区画がすっと縮み、バー全体が一瞬押しつぶされて弾み、合計が 97.4K まで下がってボタンが「Undo」に変わる。最後に Chat が元の長さへ戻る。
仕様:
- 淡いミントの地に深い松葉色 #0F3B37 のカード（角丸 20px、余白 16px）。バーは高さ 40px、区画の間は 3px、両端の角丸 6px・つなぎ目 2px。合計の窓は 200K
- System 4.2K・Tools 12.8K・Files 46.1K・Chat 108.6K・Memory 3.9K を大きい順に並べ、合計 175.6K。色は System 琥珀、Tools 紫、Files 青、Chat 青緑、Memory 薔薇色で、残りは白 12% の帯
- ポインタは 0.3 秒に入り、0.8 秒に System、1.88 秒に Files、2.74 秒に Chat を指し、3.55 秒にバーを離れる。指していない区画は 0.22 秒で 0.22 まで薄くなる
- 数字は変わった桁だけ 0.18em 下か上、2px のぼかしから 0.5 秒で過ぎ戻りしながら現れ、左から 70ms ずつ遅れる。古い桁は 0.16 秒で消える
- 4.0 秒に「Compact」を押すと Chat が 0.82 秒で 30.4K に縮み、合計は 97.4K になる。各区画は 55ms ずつずれて 0.76 秒の押しつぶし（Chat 0.78、ほか 0.93、戻りで 1.03）を受ける
- ポインタは 4.75 秒に去る。5.4 秒に Chat が同じ 0.82 秒の曲線で 108.6K に戻り、ボタンも「Compact」に戻る
使いどころ: AI チャットやコーディングアシスタントの使用量表示、トークン予算のダッシュボード、ストレージ内訳の表示などに。
