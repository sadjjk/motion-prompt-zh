「ローリングテキストボタン（Rolling text button）」を使ってください。「LP・Webサイトの演出」の名前の1つです。
Motion Prompt #1-154

どういうものか: ホバーでラベルが1文字ずつ上へ転がって入れ替わる
見本で起きること: カーソルが乗るとラベルの文字が左から順に上へ抜け、下から同じ文字が出てくる。ボタンは白から墨色に反転し、丸い矢印が右上を向く。
仕様:
- 220×56のカプセル型ボタン。左にラベル、右に直径40pxの丸い矢印。カーソルは0.6秒で乗る
- 各文字が0.035秒ずつずれ、0.55秒（easeInOut 3乗）で1行分（26px）上へ抜け、下から同じ文字が入る
- 同時にボタンの地は白 → 墨色、文字は墨色 → 白、丸は墨色 → 朱色になり、矢印は → から ↗（−45°）へ回る
- 3.4秒でカーソルが離れ、すべて逆向きに戻る
使いどころ: ポートフォリオやブランドサイトの主要ボタンなど、遊び心のある CTA にしたい所に。

参考実装（Canvas 2D・時刻だけで絵が決まる関数）: https://sadjjk.github.io/motion-prompt-zh/api/v1/ja/e/1-154.txt
共通の補助コード: https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/lp.js
参考実装の形・タイミング・イージングの数値はそのまま使い、中の文字・色・素材だけ、いま作っている物に合わせてください。
