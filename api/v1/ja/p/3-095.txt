「15秒CM台本（15-second ad script）」を使ってください。分類は「カメラ・編集 / 絵コンテ・テンポ」です。
Motion Prompt #3-095

どういうものか: 0〜3秒フック、3〜10秒にポイント2つ、10〜13秒に使う場面、最後の2秒に商品とキャッチコピーを置く15秒CMの組み立て
見本で起きること: 4コマの幅が3 : 7 : 3 : 2秒の比で、ポイントの区間がいちばん長く、締めがいちばん短いのがひと目でわかる。「钩子」はボトルが上から落ちて弾み、赤字「摔不坏？」。「卖点 × 2」は前半が黒バックのサイドライトで溝が光り、後半は湯気が立ち、数字が12hまで数え上がって「保温」。「使用」は屋外で手に持つ。「产品 + 口号」は淡い青の無地の背景でボトルが中央、下に青い帯のキャッチコピー。コマの下に3s・7s・3s・2s、隅に経過秒「07 / 15s」。
仕様:
- 9.4秒周期。15秒を1秒＝0.55秒に縮め、0.3秒から8.55秒まで再生
- 4コマの幅は3 : 7 : 3 : 2。「卖点 × 2」の前半は滑り止め、後半は湯気と0から12hへのカウント
- 締めのコマ：コマの15〜40%でキャッチコピーの帯が現れる
- 8.8〜9.4秒に最初の画面へフェードで戻る
使いどころ: SNS広告やEC用の15秒動画の台本を、時間配分から組み立てたいとき。
