Motion Prompt #3-096

どういうものか: とても横長のバナーで、主役を中央に置いて左右は切れてもよくし、シェア時の正方形の切り抜きにも耐える画像
見本で起きること: 海辺の横長バナーが上下2段に並ぶ。中央に正方形の琥珀色の点線枠がかかり、枠の外が白く薄くなる。切り抜かれた正方形が右へ滑り出る：上段は人物が中央なので正方形にも全身が入り緑の枠と ✓「主体居中」、下段は人物が左寄りなので正方形で半分切れて赤の枠と ✕「主体偏一侧」。上に「横幅 2.35 : 1」「正方形 1 : 1」の表示。
仕様:
- 5秒周期。0.3〜0.8秒にバナー2.35 : 1が出て、1.0〜1.6秒に中央の正方形枠と枠外の白（不透明度0.62）
- 1.9〜2.6秒に切り抜いた正方形が右のx 318へ滑り、枠が緑（完全）か赤（切れた）になる
- 2.8〜3.2秒に ✓ / ✕ と説明が出る
- 4.4〜4.95秒にすべて消えて最初に戻り、5秒と0秒は同じ画面
使いどころ: 公众号の記事ヘッダーや横長バナーなど、あとで別の比率に切り抜かれる画像を作るとき。
