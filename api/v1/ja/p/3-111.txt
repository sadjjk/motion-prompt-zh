「日本風の透明感（Japanese airy look）」を使ってください。分類は「光と色 / ムード・トーン」です。
Motion Prompt #3-111

どういうものか: 明るめの露出、低いコントラスト、青みや暖かみのある淡い色、日常の場面にたっぷりの自然光で、空気の澄んだ感じを出すこと
見本で起きること: 空・海・海辺の道を自転車の人物が走る、コントラストの強い平凡な画面から始まる。道の破線が流れ、ペダルが回り続ける。まず暗部が持ち上がり、黒い部分が灰青色になる。次に人物の後ろ上に逆光が光り、人物の縁に明るい線が出る。続いて全体が青緑に寄る。最後に白っぽい薄いベールがかかってコントラストが下がり、明るく淡い完成形になる。右のチェックリストは要素が入るごとに番号の丸が青くなり、状態が「平淡版 → 叠加中 → 成品」と変わる。
仕様:
- 5秒周期。0〜0.6秒は平凡な版。4つの要素が0.6秒から0.7秒ごとに1つずつ加わり、それぞれ0.5秒で入る
- 道の破線は46pxおきで1周に5本ぶん流れ、ペダルは1周に2回転。暗部：#8E9AA6 のスクリーンで黒が灰青に
- 逆光：(270, 40) から半径200pxの光、シルエットを1.5pxずらした明るい縁。青緑：#CDEBDF を乗算。コントラスト：白0.3を重ねる
- 4.4秒まで完成形で止まり、4.4〜4.95秒に平凡な版へ戻る。5秒と0秒は同じ画面
使いどころ: 日常のスナップ・旅行・夏の写真を、明るく澄んだ空気感にしたいとき。
