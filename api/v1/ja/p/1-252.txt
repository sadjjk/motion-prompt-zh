「サイズ超過を断るアップロード枠（Upload drop box that refuses big files）」を使ってください。分類は「コンポーネント / 開く・重なる」です。
Motion Prompt #1-252

どういうものか: ファイルを落とすと枠が吸い込んでアップロードを見せ、上限を超えるファイルは首を振るように揺れて赤くなり、同じファイルをもう一度落とすと少し皮肉を言って突き返す
見本で起きること: 明るい黄色からオレンジがかった黄色へのグラデーションの地に、右側に琥珀色の影を落とす青い角丸のドロップ枠があり、白い矢印のタイルと Drag a file here、Up to 5 MB の文字が並ぶ。左のトレーには緑の PNG ラベルの mood.png と紫の MP4 ラベルの demo.mp4 が置かれている。ポインタが画像をつかんで枠へ運ぶと、枠は明るい青にふくらみ矢印が上がって Drop to upload になる。手を離すと画像は細くつぶれながら中心へ吸い込まれ、枠はアップロード行の大きさまで縮み、％の数字が転がってミント色のバーが満ち、緑のチェックが弾んで出る。画像がトレーに戻ると、今度は動画を枠に落とす。枠は左右に揺れて赤くなり Too big — up to 5 MB と言い、動画はばねでトレーへ跳ね戻る。もう一度落とすと文言が Still 12.6 MB. It didn't shrink. に変わり、しばらくして文字が消え、枠は青に戻る。
仕様:
- ドロップ枠は 300×176 px、角丸 20 px で、黄色の地に青。Drag a file here と Up to 5 MB を表示し、左のトレーに mood.png（2.4 MB）と demo.mp4（12.6 MB）を置く
- 0.5 秒にポインタが画像をつかみ（1.08 倍、傾きは最大 6°）枠の上へ運ぶ。枠は 1.02 倍にふくらみ、矢印を 4 px 上げて Drop to upload に変わる。1.0 秒に離すと、ファイルは 0.38 秒で中心へ吸い込まれる
- 枠はアップロード行の大きさに縮み、1.22 秒から 2.57 秒まで ％ が転がってミント色のバーが満ち（1.35 秒。原作の speed 50 での 2.37 秒を周期に収めるため短縮）、緑のチェックが弾む。3.27 秒に画像がトレーへ戻る
- 2.95 秒に 12.6 MB の動画を枠へ運び、3.55 秒に落とす。枠は 0.42 秒左右に揺れて赤くなり Too big — up to 5 MB と表示し、ファイルは bounce 40 のばねで 0.42 秒かけて元の場所へ戻る
- 4.38 秒に同じファイルをもう一度落とすと文言が Still 12.6 MB. It didn't shrink. に変わる。表示は最初の拒否から 1.8 秒後の 5.35 秒に消え、枠は青に戻る
使いどころ: ファイルのアップロード画面、添付の受け付け、容量制限のある投稿フォームで、上限超過を責めすぎずに伝えたいときに。
