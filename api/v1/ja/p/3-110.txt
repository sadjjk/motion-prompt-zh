「癒やし（Healing vibe）」を使ってください。分類は「光と色 / ムード・トーン」です。
Motion Prompt #3-110

どういうものか: 暖かく柔らかい光、ゆっくりした間、日常の小物と余白で、見る人をほっとさせること
見本で起きること: 窓辺の台に湯気の立つお茶のカップが置かれた、冷たい色の平凡な画面から始まる。まず窓が暖かい色になり、低い日差しが斜めに台に落ち、カップの長い影が伸びる。次に左下から縞のあるブランケットが滑り込む。続いて全体に暖かい白がかかってコントラストが下がり、細かい粒子がちらつく。最後にカメラがごくゆっくりカップへ寄る。湯気はずっとゆらゆら揺れている。右のチェックリストは要素が入るごとに番号の丸が青くなり、状態が「平淡版 → 叠加中 → 成品」と変わる。
仕様:
- 5秒周期。0〜0.6秒は平凡な版。4つの要素が0.6秒から0.7秒ごとに1つずつ加わり、それぞれ0.5秒で入る
- 低い暖かい日差しが窓から台へ斜めの帯になり、カップの長い影。ブランケットは左から60px滑り込み、2本の縞
- 暖かい白0.28でコントラストを下げ、520粒の粒子が1秒に12回跳ぶ。ごくゆっくり寄る：2.7〜4.4秒に1倍から1.1倍。湯気は1周に1往復
- 4.4秒まで完成形で止まり、4.4〜4.95秒に平凡な版へ戻る。5秒と0秒は同じ画面
使いどころ: 暮らし・カフェ・読書・休日のVlogなど、ゆったりした日常を見せたいとき。
