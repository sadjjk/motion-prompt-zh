Motion Prompt #4-066

どういうものか: 暗い画面に一文ずつ大きな字幕を出し、キーワードを黄色で塗り、数字を回して決める、音なしでも読めるSNSニュースのスタイル
見本で起きること: 暗い夜の街のボケが横へ流れる。左に黄色の縦線が伸び、「外卖平均」が一文字ずつ出る。続いて大きな数字が 0 から 28 まで回って止まり、右の計時リングの黄色い弧も一緒に伸びる。「28 分钟」に黄色の帯が左から敷かれ、帯の中の文字は黒に反転する。補足の一文が一文字ずつ出て、最後に出典の小さな文字が下から滑り込む。リセットでは字幕全体が上へ抜ける。
仕様:
- 数字：1.0–2.0 秒で 0 から 28 まで回る
- 黄色の帯：2.05–2.4 秒で「28 分钟」に敷かれ、中の文字は黒に反転
- 計時リング：弧の長さ = 数字 / 60 分
- 出典：3.6 秒に下から滑り込む
- リセット：5.4–6.0 秒に字幕全体が 208 px 上へ
使いどころ: データニュース、どんでん返しのある話、音なしで見られる速報に。
