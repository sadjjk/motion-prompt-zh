Motion Prompt #3-058

どういうものか: 被写体を画面の真ん中に置き、視線をまっすぐ集める
見本で起きること: 人物が左から画面の中心線へ移り、中心線と頭から胸にかけての視覚の重心を示す円が現れる。背景は左に建物、右に木で左右対称ではない。
仕様:
- 人物: x 150 から中心線 x 270 へ、身長110px
- 中心線は x 270 の縦の破線。重心の円は半径28px・中心 y 118、右に「视觉重心」
- 背景は鏡像にしない。左 x 60 に建物、右 x 432・x 470 に木2本。真ん中に置くのは重心のためで対称のためではない
- 補助線: 琥珀色 #F5A524 の破線、太さ1.6px。効果の量に合わせて現れる
- 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、イーズインアウト）
使いどころ: 商品写真・正面の人物写真など、主役を一つに絞りたいときや改まった印象にしたいとき。
