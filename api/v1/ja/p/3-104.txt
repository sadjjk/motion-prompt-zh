「空気感（Atmospheric mood）」を使ってください。分類は「光と色 / ムード・トーン」です。
Motion Prompt #3-104

どういうものか: 光・空気中の霧や煙・色調をいっしょに使って、画面に気分をもたせること
見本で起きること: 8本の幹が並ぶ森の小道に人物が立つ平凡な画面から始まる。まず空気に霧が入り、地平線に近いほど濃く、奥の木ほど白く霞む。次に木の後ろの太陽が光り、6本の光の筋が霧を抜けて、ゆっくり左右に揺れる。続いて全体が寒色に寄り、太陽のまわりだけ暖かい色が残る。最後にまわりと下が暗く沈み、中央の光の筋が浮き上がる。右のチェックリストは要素が入るごとに番号の丸が青くなり、状態が「平淡版 → 叠加中 → 成品」と変わる。
仕様:
- 5秒周期。0〜0.6秒は平凡な版。4つの要素が0.6秒から0.7秒ごとに1つずつ加わり、それぞれ0.5秒で入る
- 霧は地平線付近がいちばん濃い。太陽は木の後ろの (196, 64)、6本の光の筋は1周に1往復揺れる
- 寒色：全体に #8FB0CF を乗算し、太陽から半径46pxだけ暖色を戻す。暗部：まわりと下を最大0.7まで暗く
- 4.4秒まで完成形で止まり、4.4〜4.95秒に平凡な版へ戻る。5秒と0秒は同じ画面
使いどころ: 風景・人物・Vlogのカットに、ただきれいなだけでない気分を足したいとき。
