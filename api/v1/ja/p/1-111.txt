Motion Prompt #1-111

どういうものか: 組み合わせキーがひとつずつ押し込まれて光る
見本で起きること: 暗いキーボード板の上で Ctrl・Shift・P が順に押し込まれて琥珀色に光り、案内文が組み立てられ、板が軽く脈打ってから「キューに追加」に変わる。
仕様:
- 暗いキーボード板 510×168 に3つのキー Ctrl / Shift / P（幅 87 / 87 / 55・高さ55・間隔8.7・角丸8.7）。1.10 / 1.45 / 1.85秒に順に押されたままになる
- 押すとキー面が #292524 から琥珀 #fbbf24 に、枠が #f59e0b になり、キーが2.5px沈む。下の影は5pxの黒 #0c0a09 から2.5pxの茶 #92400e に縮む（瞬時に切り替え）
- 案内文:「押すと公開」→ 1.45秒「Ctrl + Shift + P」→ 1.85秒 全体が琥珀色で「· 公開」が付く → 2.6秒「キューに追加」。2.2〜2.6秒に板が1.02倍に拡大して1に戻る（各0.2秒）
- 3.2〜3.95秒に板が sine.inOut で5px浮く。リセット 3.95〜4.35秒 easeInOutCubic: 3つのキーが同時に上がり、案内文がクロスフェードで「押すと公開」に戻る
- ツールチップとの違い: キーを押す様子で組み合わせキーを見せ、案内文も押した分だけ完成していく。ボタンの横に添える説明ではない
使いどころ: アプリやツールの機能紹介、オンボーディング、ショートカット一覧、リリースノートでの操作説明に。
