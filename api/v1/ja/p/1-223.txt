「ストラップ付き名札（Lanyard badge）」を使ってください。分類は「ポインター操作 / 手触り・カード」です。
Motion Prompt #1-223

どういうものか: 上から垂れたストラップに名札がぶら下がり、つかんで引っ張って離すと揺れながら戻る効果
見本で起きること: 名札が軽く揺れて下がっていて、1.2 秒にカーソルがつかんで右上へ引っ張り、2.6 秒に離すと名札が左右に大きく揺れ、ストラップが弾んで縮み、だんだん止まる。
仕様:
- 84×116 px の名札が長さ 84 px のストラップにぶら下がり、普段は周期 3.2 秒、±0.04 rad で揺れる
- 1.2 秒にカーソルが名札の中心をつかみ、2.5 秒までに (400, 118) へ引っ張る。ストラップの角度と長さはカーソル位置から逆算する
- 2.6 秒に離すと、振れ角は θ·e^(−2.2τ)·cos(5.2τ) で減衰し、ストラップの長さは e^(−6τ)·cos(14τ) で 84 px へ弾んで戻る
- 名札自身の回転はストラップより 0.06 秒遅れ、ストラップの中ほどがその差の分だけ曲がって振り回される感じを出す
- すべて時刻の式で計算し、フレームごとの積分はしない。5.4–6.0 秒に残った揺れを 0 にして、軽い揺れだけの 0 秒につなぐ
使いどころ: イベント、カンファレンス、採用ページ、プロフィールで、名札を触って遊べるようにしたいとき。
