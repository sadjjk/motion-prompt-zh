「すっきり（Clean look）」を使ってください。分類は「光と色 / ムード・トーン」です。
Motion Prompt #3-109

どういうものか: 要素を減らし、背景を出しゃばらせず、色と光をそろえて、すっきり見せること
見本で起きること: 小物が散らばり、壁にもいろいろ貼られ、色の違う光のしみが3つある机から始まる。まず机の上の小物7つが消え、ノートPC・カップ・観葉植物だけが残る。次に壁の4つの物が消え、壁と床が明るく退く。続いて色の光のしみが消え、全体に均一な柔らかい光がかかる。最後に色味が淡いグレーにそろう。残した3つは位置も大きさも変わらない。右のチェックリストは要素が入るごとに番号の丸が青くなり、状態が「平淡版 → 叠加中 → 成品」と変わる。
仕様:
- 5秒周期。0〜0.6秒は平凡な版。4つの要素が0.6秒から0.7秒ごとに1つずつ加わり、それぞれ0.5秒で入る
- 机の上の小物7つが消え、ノートPC・カップ・観葉植物の3つが残る。壁の4つの物が消え、壁は #F5F4F1 へ明るく
- 色の違う光のしみ3つが消え、白0.18の均一な柔光に。色味：すべての色を #EEF0F2 へ50%寄せる。素材の細部は足さない
- 4.4秒まで完成形で止まり、4.4〜4.95秒に平凡な版へ戻る。5秒と0秒は同じ画面
使いどころ: デスク・部屋・商品の写真を、整って見やすくしたいとき。
