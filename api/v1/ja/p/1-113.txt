Motion Prompt #1-113

どういうものか: ビルドの各段階が順に実行され、緑になってつながる
見本で起きること: 暗い背景に並ぶ4つの段階カードが左から順に実行され、成功すると枠と丸が緑に光り、次のカードへ線が伸びて、最後の Deploy が「公開済み」になる。
仕様:
- 4つの段階カード Lint → Test → Build → Deploy（117×124・間隔14）。つなぎ線の高さ2px、カード上端から70の位置
- 0.85秒 段階01 実行中 → 1.25秒「成功 · エラー0件」。1.70秒 段階02 実行 → 2.15秒「成功 · 128件のテスト」。2.60秒 段階03 実行 → 3.05秒「成果物の準備完了」。3.50秒 段階04 がすぐ「公開済み」
- 成功すると枠が緑 #16a34a、右上の丸が #22c55e で光り、状態の文字が緑の太字になる（瞬時）。成功から0.05秒後、つなぎ線が0.35秒（二次の easeOut）で次の段階まで伸びる
- 3.6〜3.95秒に列全体が sine.inOut で2.5px浮く。リセット 3.95〜4.35秒 easeInOutCubic: 緑の枠・丸・つなぎ線・状態の文字が「待機中」に戻る
- ステップインジケーターとの違い: 各段階に実行中と成功の状態と結果の文字があり、自動で順に進む。ユーザーが「次へ」を押して進めるものではない
使いどころ: CI/CD・ホスティング・開発基盤サービスの紹介ページや、ダッシュボードのビルド状況表示に。
