Motion Prompt #4-061

どういうものか: ドット方眼の紙に、マスキングテープ、マーカーの手書き、蛍光ペン、付箋、ボールペンのチェックを重ねる手帳風のスタイル
見本で起きること: ドット方眼の紙に、3 本のマスキングテープが端から引き出されて貼られる。マーカーで「本周计划」と書かれ、蛍光ペンが下を引く。予定 3 行が一行ずつ書かれ、青いボールペンが順にチェックを入れる。黄色い付箋「别忘了 喝水！」が弾んで貼られ、最後に落書きの星が描き足される。リセットでは付箋がはがされ、文字とテープが薄れる。
仕様:
- 紙 #FBF8F1、ドット間隔 12 px、ボールペン #2D5BD8
- 0.2 / 0.35 / 0.5 秒にテープ 3 本、各 0.3 秒で引き出す
- 0.6–1.3 秒にタイトル、0.9–1.4 秒に蛍光ペン
- 1.5 / 1.8 / 2.1 秒に予定 3 行を各 0.3 秒で書き、2.6 / 3.0 / 3.4 秒にチェック
- 3.9 秒に付箋、4.4–4.9 秒に星
- 5.4–5.8 秒に付箋がはがれ、5.6–6.4 秒に全体が薄れる
使いどころ: 勉強法、生活の工夫、習慣づくり、計画の立て方など、親しみやすく見せたい解説に。
