「シェイプモーフ（Morphing）」を使ってください。「モーショングラフィックスのスタイル」の名前の1つです。
Motion Prompt #2-051

どういうものか: 1 つの形がリズムに合わせて次々と別の形へ変わっていくモーフィングのスタイル
見本で起きること: 中央の図形が一度丸に縮んでから次の形へ開き、つぶれと回転を伴って変わるたびに背景色が円形に塗り替わり、右の字幕も入れ替わる。
仕様:
- 150 BPM の 2 拍＝0.8 秒ごとに形が変わる：0.35 秒静止 + 0.45 秒変形。8 形で周期が一巡
- 変形は A→丸→B の 2 段階で、各段 inOut3。頂点 120 個、基準半径 62px
- 変形中は最大 13% のつぶれと伸び、0.35 ラジアンの揺れ回転
- 配色 #16151B / #F4EEE3 / #FFB627 / #FF4F2B / #2438E8。背景は中心から半径 600px の円で塗り替え、字幕 40px は 24px 上へ入れ替わる
使いどころ: 音楽に合わせた SNS ショート、ブランドのキービジュアル展開、テーマが次々変わるタイトル演出に。
