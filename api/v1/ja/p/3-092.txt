Motion Prompt #3-092

どういうものか: 1ショットを1行にし、番号・長さ・景別とカメラワーク・画面・音を表に書いた台本
見本で起きること: 左の表に見出し「# / 时长 / 景别与运镜 / 画面 / 声音」があり、ショットの開始ごとに1行ずつ左から右へ書き出され、今の行は青い背景になる：引き・固定「清晨街口，她走进来」環境音、ミディアム・プッシュイン「停在咖啡店门口」足音、アップ・固定「抬眼看招牌」風鈴、バスト・固定「推门，笑着说早」「早！」、遠景・プルバック「店里暖光，她坐下」音楽が入る。右の小さな画面がその行のショットを同時に再生し、下に進行バーと「镜头 N · 景别」が出る。
仕様:
- 9.4秒周期。5行は0.4秒から始まり、長さは2.0、1.5、1.5、1.5、1.5秒で8.4秒に終わる
- 各行は開始から0.35秒で左から右へ書き出される。今の行は青い背景と左端の青い線
- 右のプレビューは160 × 100px。ショット2はカメラが4.6mから3.2mへ寄り、ショット5は後ろへ下がって通り全体が見えてくる
- 8.8〜9.4秒に最初の画面へフェードで戻る
使いどころ: ショート動画やCMを撮る前に、ショットの流れと長さを決めてチームやAIに渡すとき。
