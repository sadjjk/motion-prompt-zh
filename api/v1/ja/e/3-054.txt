// クローズアップ / Close-up
// パック: camera (カメラワークと切り替え) · element 30 · カテゴリ: ショットサイズ
// 何が起きるか: 頭と肩で画面がいっぱい。目線が横へ動き、まばたきし、体が少し引き、最後に正面へ戻る。
// 動きの仕様:
//   - 画框: 1.4mから1.85m（肩から頭の上まで）。カメラは2.6m先
//   - 目線: 0.4〜0.9秒で横へ0.05m動き、3.7〜4.4秒で戻る
//   - 1.55秒にまばたき1回。0.9〜1.3秒で体が0.05m引き、目線と一緒に戻る
//   - 背景ははっきりぼかす。右上に「特写 CU」、比例尺は肩から頭まで
//   - カメラは最後まで動かない。1周4.7秒で、最初と最後の画面は同じ
// 使いどころ: 感情の変化や反応、細かな表情に気づかせたいとき。
// タグ: close-up, cu, close up, head and shoulders, reaction, shot size, emotion
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://sadjjk.github.io/motion-prompt-zh/api/v1/kit/camera.js
// 動く見本: https://sadjjk.github.io/motion-prompt-zh/?lang=ja#3-054
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 30
// 30 特写：胸像。动作只有特写才看得清：视线先动（被什么吸引）、一次眨眼、身体轻轻退半步，末段复原；首尾正视，循环无缝
CELLS[29] = shot(frameCell({ lo: 1.4, hi: 1.85, name: '特写', abbr: 'CU', draw: (k, w, h, u) => {
  const gaze = 0.05 * eOut(P(u, 0.4, 0.9)) * (1 - P(u, 3.7, 4.4));   // 视线先动：被什么吸引
  const sway = -0.05 * eOut(P(u, 0.9, 1.3)) * (1 - P(u, 3.7, 4.4));  // 身体轻轻退半步
  const blink = clamp(1 - Math.abs(u - 1.55) / 0.09);                // 注意到时眨一次眼
  world(k, w, h, fit(1.4, 1.85, 2.6), {
    person: { x: sway, z: 8, fg: true },
    extra: [[sway, 0, 7.99, (kk, s) => face(kk, s, { gaze, blink }), true]],
    blurBg: 2.0
  });
} }));
