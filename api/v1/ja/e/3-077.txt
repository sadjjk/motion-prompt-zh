// 動きの仕様:
//   - 場面③: 左に胸像（頭の中心 x140, y82・半径28px）、右に丘・家・木・太陽（x432, y54・半径15px）。
//   - 色: 空 #FAF9F7 → #2B2D33、丘 → #313339・#36383E、地面 → #24252A、人物 → #25272E。太陽と光の輪は空と同じ色になって消える
//   - 胸像の右の縁（光の面）は残り、#FFC75A → #FFB547
//   - ヒストグラム: 山の中心 0.56 → 0.14、幅 0.2 → 0.08
//   - 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 高級感・緊張感・ミステリアスな雰囲気を出したいとき。
// タグ: low-key, low key, dark, black background, moody, dramatic, chiaroscuro
// サイズ: 539x208 px · 1周: 5 s

// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここからこの効果のコード。CELLS や定数・補助関数は依存する共通コードにある。

// @element 18
// ローキー: 画面の大半が暗く沈み、横からの光が当たる縁だけが浮かぶ
CELLS[17] = cell((k, u) => {
  const a = env(u);
  const LOW = Object.assign({}, DARK, { sun: DARK.sky, glow: DARK.sky, person: '#25272E', lit: '#FFB547' });
  stageLand(k, pal(BASE, LOW, a));
  histo(k, lerp(0.56, 0.14, a), lerp(0.2, 0.08, a));
});
